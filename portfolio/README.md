## My Projects

Here are some of the key projects I've worked on:

### 1. Finest Diners - Food Delivery Platform
![Finest Diners](src/assets/advert2.jpeg)

A sophisticated, full-featured food delivery platform that goes far beyond a basic restaurant menu. This advanced frontend application demonstrates complex real-time features and modern development practices.

**Core Customer Experience Features:**
- **Restaurant & Menu Browsing**: Rich media experience with hero videos and food images, category filtering, and detailed item information
- **Smart Cart System**: Real-time cart updates with quantity controls, automatic price calculations, and restaurant mixing prevention
- **GPS-Based Checkout**: Automatic location detection using browser geolocation API with reverse-geocoding to readable addresses
- **Payment Processing**: Multiple payment methods (Card, Apple Pay, Cash on Delivery) with Paystack integration
- **Real-Time Order Tracking**: Live order status updates via Socket.IO and GPS tracking of delivery drivers

**Technical Implementation:**
- **Modern Tech Stack**: React 19 + Vite 8 + Tailwind CSS 4 + Framer Motion
- **Advanced Features**: JWT authentication, Socket.IO real-time communication, geolocation services
- **Sophisticated UI/UX**: Scroll-scrubbed hero videos, draggable components, animated transitions
- **Performance Optimizations**: Request caching, lazy loading, optimized assets
- **Security**: Protected routes, secure API communication, automatic session management

**Tech Stack:** React 19, Vite 8, Tailwind CSS 4, Framer Motion, Socket.IO, Axios, React Router 7  
**Live Demo:** [https://finest-diners-2-rihd.vercel.app/](https://finest-diners-2-rihd.vercel.app/)  
**GitHub:** [https://github.com/gtra5/finest-diners-2.git](https://github.com/gtra5/finest-diners-2.git)

## Technologies Used

- **React**: For building the user interface and managing component state.
- **Vite**: For fast development, hot module replacement (HMR), and optimized builds.
- **JavaScript (JSX)**: For writing component logic and structure.
- **CSS**: For styling and layout, including custom animations.
- **ESLint**: For maintaining code quality and consistency.
- **Firebase**: For authentication and backend services.
- **Tailwind CSS**: For utility-first styling approach.
- **Socket.IO**: For real-time bidirectional communication.
- **Sketchfab API**: For 3D model integration.
- **TMDb API**: For movie data integration.
- **DummyJSON API**: For e-commerce product data.
- **Paystack**: For payment processing.
- **OpenCage API**: For reverse geocoding services.

## Getting Started

To run this portfolio locally:

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
